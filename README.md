## Sobre o projeto

O **Client Prospector** foi desenvolvido para facilitar a **prospecção de potenciais clientes**, reunindo informações relevantes de empresas e contatos para apoiar processos comerciais e de geração de oportunidades.

## Funcionalidades

* Pesquisa de potenciais clientes
* Identificação de empresas e contatos
* Coleta e organização de informações
* Processamento de múltiplos registros
* Estruturação dos dados para prospecção
* Interface web intuitiva

## Tecnologias

* Python
* FastAPI
* JavaScript
* HTML5
* CSS3
